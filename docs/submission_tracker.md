## Blind review

Papers are now built **double-blind**: the title page shows "Anonymous
Author(s)" / "Submitted for double-blind review" instead of the real name
and affiliation, and the Related Work sections' self-citations were
reworded to remove first-person/self-identifying phrasing ("the author's
own prior work" -> neutral third-person description). The bibliography
still lists the real self-citations by name (standard practice -- citing
your own prior published work is fine under double blind; only claiming
it in the first person is not). A non-anonymized version with the real
author block can be regenerated by reverting the `\author`/`\institute`
lines and the two reworded paragraphs if a venue turns out to want
single-blind instead.
- Both venues share the same submission portal (myproconf.com), the same LaTeX/Word templates, and near-identical page wording -- likely the same organizing group running multiple similarly-branded regional conferences.
